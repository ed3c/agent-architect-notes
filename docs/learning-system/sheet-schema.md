# Google Sheets Schema

Google Sheets is the execution database. GitHub is the knowledge base.

## Tabs

| Tab | Purpose |
| --- | --- |
| Setup | Operating overview and key links. |
| Settings | Start date, timezone, cadence, scoring weights. |
| Daily Plan | 28 weeks of scheduled 09:00 / 14:00 / 19:00 sessions. |
| Session Log | Actual execution record and weighted score. |
| Daily Summary | Date-level completion and average score. |
| Dashboard | KPI view and readiness signal. |
| LeetCode Tracker | Problem bank, pattern, stage, invariant, bug alarm. |
| Production Labs | Production live coding labs and evidence. |
| System Design | System design topics and answer skeleton. |
| English Drills | Daily English interview practice. |
| Exercise Log | Granular exercise evidence and next review date. |
| Scoring Rubric | Weight definitions. |
| GitHub Docs Index | Repository document URLs. |
| Knowledge Index | Domain-level knowledge map. |
| First Task | Two Sum starter exercise and required tests. |

## Required Evidence URL Rule

Every detailed note URL should point to this private GitHub repository. Use Google Sheets only for status, score, and index fields.

## Session Log Required Fields

- Plan ID
- Date
- Time
- Phase
- Track
- Planned Task
- Status
- Minutes
- Correctness / Independence / Tests / Explanation / Review / Energy
- Weighted Score
- Evidence URL
- GitHub Doc URL

## Exercise Log Required Fields

- Exercise ID
- Date
- Type
- Pattern / Ability
- Stage
- Contract Passed
- Tests Passed
- Edge Cases
- What-if Completed
- English Explanation
- Score
- Next Review Date
- Memory Capsule URL
