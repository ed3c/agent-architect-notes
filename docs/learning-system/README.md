# Learning System

This folder defines the daily learning system for Agent Architect transition work.

## Core Judgment

Do not use the sequence `Python syntax -> 300 LeetCode problems -> Agent Architect applications` as the main strategy.

Use two tracks in parallel:

1. **Interview floor**: Python 3, Data Structures, Algorithms, Testing, SQL, and clean live coding.
2. **Hiring ceiling**: Production-grade Agent Systems, Evals, Security, Observability, System Design, and measurable portfolio evidence.

The target identity is:

> Senior Software Engineer transitioning into Agentic AI Systems

Existing Android, debugging, system design, and product delivery experience should be preserved and converted into AI Product / Full-stack / Agent Platform evidence.

## Daily Operating Loop

- 09:00: concept learning, mental scene, or architecture model.
- 14:00: independent implementation, tests, or design skeleton.
- 19:00: active recall, memory capsule, English explanation, and next action.

Every session writes status and score to the Google Sheets dashboard.

## Gates

A topic is not complete when it is merely watched or read. It is complete only when the learner can:

- Reconstruct the solution or design without opening the answer.
- State the invariant or business invariant.
- Run or describe tests and counterexamples.
- Explain time/space or system trade-offs.
- Answer at least one what-if variant.
- Leave a traceable evidence URL in the Sheet.

## Primary Artifacts

- Dashboard: execution status, scoring, trends, and evidence URLs.
- Daily Plan: 28 weeks of 09:00 / 14:00 / 19:00 sessions.
- Session Log: actual execution record.
- Exercise Log: LeetCode, production lab, system design, and English drill records.
- Knowledge Index: GitHub source of truth for long-form notes.
- Discord Prompt Catalog: 依 `INFERENCE` 頻率排序、可獨立複製的 Prompt Families 與
  Agent Architecture Issue Applications。
