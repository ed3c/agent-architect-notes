# Daily Cadence

Timezone: `Asia/Taipei`

Default daily updates start at 09:00 and repeat every five hours during the learning day:

| Time | Purpose | Output |
| --- | --- | --- |
| 09:00 | Concept + Warm-up | Problem contract, mental scene, concept map, or system boundary. |
| 14:00 | Practice + Implementation | Independent code, tests, production lab, or design skeleton. |
| 19:00 | Review + English | Active recall, memory capsule, English explanation, and next action. |

## Session Rules

Each session should produce one of these evidence types:

- Code commit or local exercise file.
- Test output or failure note.
- Memory capsule.
- System design note.
- English explanation recording/transcript.
- Postmortem or repair note.

## 09:00 Rule

Start with input, not output. For LeetCode, this means problem contract and mental scene before code. For system design, this means business objective and system boundaries before architecture boxes.

## 14:00 Rule

Practice must be independent. Hints are allowed only when the session is marked `Guided`. If the status is `Independent`, no copied answer, AI autocomplete, or solution lookup should be used.

## 19:00 Rule

Review uses active recall first. Do not reread the solution before trying to reconstruct:

1. 10-second mental movie.
2. Invariant.
3. Bug alarm.
4. Complexity.
5. One what-if pivot.

## Status Meanings

- `Planned`: not started.
- `In Progress`: started but not scored.
- `Done`: evidence produced and score entered.
- `Blocked`: concrete blocker exists.
- `Skipped`: intentionally skipped.
- `Review`: completed once and scheduled for active recall.
