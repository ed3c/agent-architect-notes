# 28-Week Roadmap

This roadmap uses capability gates rather than week count alone.

| Phase | Weeks | Main Content | Required Output | Upgrade Condition |
| --- | --- | --- | --- | --- |
| 0. Baseline | Week 0 | Python, DSA, SQL, System Design, English diagnosis | Gap Matrix | Baseline established. |
| 1. Python Interview Foundation | Weeks 1-3 | Python object model, collections, typing, pytest, OOP, exceptions | 20 small functions, 12 Easy problems, tests | New Easy in 15 minutes. |
| 2. Core LeetCode Patterns | Weeks 4-10 | Hash, Window, Stack, Binary Search, Tree, Heap, Graph, DAG, Trie, DP | 60-70 high-value problems | New Medium in 35 minutes at >=70% pass rate. |
| 3. Production Live Coding | Weeks 8-14 | API, Pydantic, asyncio, retry, queue, rate limiter, logging | 8-10 production labs | Runnable version + tests in 60 minutes. |
| 4. System Foundations | Weeks 11-18 | Networking, DB, Cache, Queue, Consistency, SQL, Distributed Systems | 8+ system design notes | Defensible 45-minute design. |
| 5. Agent Architect Core | Weeks 16-23 | Orchestration, State, Memory, Tool Contract, Evals, Security, Observability | Agent Architecture Capstone | 60-minute architecture defense. |
| 6. AI Engineer / FDE Branches | Weeks 20-25 | RAG, PyTorch basics, FDE decomposition, Data Pipeline | 2 AI cases, 2 FDE cases | Role-specific trade-offs explained. |
| 7. English Interview Campaign | Weeks 24-28 | Coding, refactoring, system design, deep dive, behavioral | 6 full mocks, resume, demo | Two consecutive loops pass. |

## Recommended Effort Split

| Capability | Ratio |
| --- | ---: |
| Python 3, LeetCode, SQL | 25% |
| Production Live Coding, Testing, Debugging | 25% |
| System Design, Agent Architecture | 30% |
| English Interview, Behavioral, Application | 20% |

## Interview Loop Target

1. Recruiter / Hiring Manager — 30 min.
2. Coding & Algorithms — 50 min.
3. Production Live Coding / Refactoring — 60 min.
4. Agentic System Design — 60 min.
5. Project Deep-Dive — 45 min.
6. Behavioral / Leadership — 45 min.

Full English-only mocks begin only after independent solving and explanation gates are stable.
