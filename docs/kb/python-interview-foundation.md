# Python Interview Foundation

## Interview Python

Know these without stopping to search syntax:

- list, tuple, dict, set
- Mutability, hashability, reference semantics
- List / dict / set comprehension
- Sorting with `key`
- `enumerate`, `zip`, `range`
- `collections.Counter`
- `collections.defaultdict`
- `collections.deque`
- `heapq`
- `bisect`
- `itertools`
- Recursion
- Generator
- Type hints
- Big-O of Python containers

## Production Python

Agent Architect work needs more than LeetCode Python:

- `dataclass`
- `Enum`
- `Protocol`
- `TypedDict`
- Pydantic V2
- Exceptions and error taxonomy
- pytest
- Mocking and fixtures
- asyncio
- Task cancellation
- Timeout and bounded concurrency
- Context managers
- Structured logging
- Configuration and secrets
- Packaging with `pyproject.toml`
- Ruff, Mypy, GitHub Actions
- Profiling, memory, I/O bottlenecks
- Multiprocessing vs threading vs async

## Minimum Function Standard

Every small function should include:

- Type hints
- Clear contract
- Unit tests
- Edge-case tests
- Complexity note
- Failure behavior

## First Gate

A new Easy problem should be solvable in 15 minutes with tests and a short explanation.
